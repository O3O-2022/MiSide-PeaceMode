- Elle s'inquiète quand la batterie de votre portable faiblit
- Gentille Mita se souvient jusqu'où vous êtes allé dans l'histoire

## Installation

<img src="../media/setup_en.png" width="520" alt="MiSide Peace Mode Setup">

1. Téléchargez **MiSidePeaceMode-Setup** depuis la page [Releases](https://github.com/O3O-2022/MiSide-PeaceMode/releases/latest) et lancez-le.
2. Cliquez sur **Installer** : le programme trouve le dossier du jeu et ajoute BepInEx (le chargeur de mods) s'il manque.
3. Lancez le jeu avec le bouton **Lancer le jeu** ou le raccourci du bureau, puis choisissez **Mode Pacifique** dans le menu principal.

Toutes les fonctionnalités, avec des GIF, sont dans le [README principal](../../README.md) (en coréen).
