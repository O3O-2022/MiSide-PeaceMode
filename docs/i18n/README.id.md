**⬇ Unduh dan pasang (gratis, dengan penginstal)** — [github.com/O3O-2022/MiSide-PeaceMode/releases](https://github.com/O3O-2022/MiSide-PeaceMode/releases/latest)

Memperkenalkan "Mode Damai", mod buatan penggemar untuk MiSide (AIHASTO): sehari bersama salah satu dari tujuh Mita, tanpa horor.

- Mengobrol, bertanya, mengelus, memeluk, berpegangan tangan, memuji, kacamata, pakaian
- Batu-gunting-kertas, sambung kata, tebak-tebakan, cham-cham-cham, petak umpet, foto, permainan kartu
- Duel dansa dan permainan palu (Mita si Pemakai Topi, bab 7)
- Berkeliling rumah, jendela, pangkuan, lagu, obrolan dari hati ke hati
- Benda-benda di rumah, permintaan dan ajakannya, buku harian
- Memasak, makan, dan tidur bersama; TV, buku, dan bersantai di sofa
- Cuaca dan musim, 10 tingkat kasih sayang, reaksi terhadap apa yang kamu lakukan di luar game (Alt+F4 dll.)
- Animasi dan dialog dari berbagai bab game aslinya
- Hadiah — tiap Mita punya favoritnya sendiri
- Waktu spesial — mendengarkan musik bersama
- Dia khawatir saat baterai laptopmu hampir habis
- Mita Ramah ingat sejauh mana kamu memainkan ceritanya

## Pemasangan

<img src="../media/setup_en.png" width="520" alt="MiSide Peace Mode Setup">

1. Unduh **MiSidePeaceMode-Setup** dari halaman [Releases](https://github.com/O3O-2022/MiSide-PeaceMode/releases/latest) lalu jalankan.
2. Klik **Install**: program menemukan folder game dan menambahkan BepInEx (pemuat mod) jika belum ada.
3. Mulai game dengan tombol **Start the game** atau pintasan desktop, lalu pilih **Mode Damai** di menu utama.

Semua fitur beserta GIF ada di [README utama](../../README.md) (bahasa Korea).
