- 会話、質問、なでる、ハグ、手をつなぐ、ほめる、メガネ、着替え
- じゃんけん、しりとり、なぞなぞ、チャムチャムチャム、かくれんぼ、写真、カードゲーム
- キャッピーのダンスバトルとハンマーゲーム(原作7章)
- 一緒に歩く、窓の外、ひざまくら、歌、本音
- 家の中の物、ミタのお願いと誘い、今日の日記
- 一緒に料理・食事・睡眠、ソファでテレビ・本・休憩
- 天気と季節、10段階の好感度、ゲーム外の行動への反応(Alt+F4 など)
- 原作各章のアニメーションとセリフを活用
- プレゼント — ミタごとに好きな贈り物が違います
- 特別な時間 — 一緒に音楽を聴く
- ノートPCのバッテリーが減ると心配してくれます
- 親切なミタは本編をどこまで進めたか覚えています

## インストール

<img src="../media/setup_en.png" width="520" alt="MiSide Peace Mode Setup">

1. [Releases](https://github.com/O3O-2022/MiSide-PeaceMode/releases/latest) から **MiSidePeaceMode-Setup** をダウンロードして実行します。
2. **インストール** を押すと、ゲームフォルダーを見つけ、BepInEx（MODローダー）がなければ自動で入れます。
3. **ゲームを起動** ボタンかデスクトップのショートカットでゲームを起動し、メインメニューで **ピースフル・モード** を選びます。

各機能のGIF付き紹介は[メインのREADME](../../README.md)（韓国語）にあります。
