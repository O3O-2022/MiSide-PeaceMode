介绍 MiSide（AIHASTO）的粉丝自制模组「和平模式」：没有恐怖剧情，与七位米塔之一共度一天。

- 聊天、提问、摸头、拥抱、牵手、夸奖、眼镜、换装
- 石头剪刀布、词语接龙、脑筋急转弯、啪啪啪、捉迷藏、拍照、纸牌游戏
- 帽子米塔的斗舞与锤子游戏（原作第7章）
- 一起走、看窗外、膝枕、唱歌、心里话
- 家中物品、米塔的请求与提议、今日日记
- 一起做饭、吃饭、睡觉；沙发上看电视、读书、休息
- 天气与季节、10级好感度、对游戏外行为的反应（Alt+F4 等）
- 运用原作各章节的动画与台词
- 送礼物 — 每位米塔喜欢的礼物都不同
- 特别时光 — 一起听音乐
- 笔记本电量不足时，她会为你担心
- 善良米塔记得你主线玩到了哪里

## 安装

<img src="../media/setup_en.png" width="520" alt="MiSide Peace Mode Setup">

1. 从 [Releases](https://github.com/O3O-2022/MiSide-PeaceMode/releases/latest) 下载 **MiSidePeaceMode-Setup** 并运行。
2. 点击 **安装**：它会找到游戏文件夹，如果没有 BepInEx（模组加载器）会自动装好。
3. 用 **启动游戏** 按钮或桌面快捷方式启动游戏，然后在主菜单选择 **和平模式**。

每个功能的 GIF 演示见[主 README](../../README.md)（韩语）。
