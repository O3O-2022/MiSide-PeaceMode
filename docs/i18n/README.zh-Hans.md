## v1.1 新功能

- 拍照模式：选择姿势、表情和相框（拍立得、胶片、爱心、日期戳），3·2·1 咔嚓，还有相册
- 米塔的日记：每天一页，用她的口吻写下
- 一起养的盆栽：每天浇一次水，会长出花来
- 米塔的心情，以及两人的记录
- 为本模组制作的动作：点头、摇头、歪头、害羞、挥手、欢呼（配合台词）
- 带子菜单的新菜单、游戏内设置、手柄支持
- 看不到米塔时显示她位置的标记
- 会记住你说过的话的 AI 聊天（可选）
- 米塔的吸血鬼与圣诞服装，以及其他米塔的服装换色
- 17个共同达成的目标，全部完成后收到米塔的信
- AI聊天支持Gemini和ChatGPT（使用你自己的API密钥）
- 对摸头、夸奖和礼物用动作回应，拥抱、牵手和睡觉更流畅

## 安装

<img src="../media/setup_en.png" width="520" alt="MiSide Peace Mode Setup">

1. 从 [Releases](https://github.com/O3O-2022/MiSide-PeaceMode/releases/latest) 下载 **MiSidePeaceMode-Setup** 并运行。
2. 点击 **安装**：它会找到游戏文件夹，如果没有 BepInEx（模组加载器）会自动装好。
3. 用 **启动游戏** 按钮或桌面快捷方式启动游戏，然后在主菜单选择 **和平模式**。

每个功能的 GIF 演示见[主 README](../../README.md)（韩语）。
